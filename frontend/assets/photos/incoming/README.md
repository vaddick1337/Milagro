# Фото студии — сюда

Положите сюда файлы с фотографиями, и запустите:

```bash
python tools/apply_photos.py            # обработать и подставить в сайт
python tools/apply_photos.py --dry-run  # сначала посмотреть план
```

Скрипт сам повернёт кадр по EXIF, уменьшит до 2000 px по длинной стороне,
сохранит JPEG и миниатюру 640 px, а затем подставит пути в `mock/catalog.json`
и `mock/site.json`. Форматы: `.jpg`, `.jpeg`, `.png`, `.webp`.

## Как назвать файлы

| Имя файла | Куда попадёт |
| --- | --- |
| `p-01` … `p-17` | фото товара с этим id (список — в `mock/catalog.json`) |
| `hero-1` … `hero-5` | кадр баннера на главной, по порядку |
| `hero-1-mobile` | отдельный кроп этого кадра для телефона (необязательно) |
| `cat-bouquets` | обложка категории «Букеты» |
| `cat-fresh` | обложка «Свежие цветы» |
| `cat-dried` | обложка «Сухоцветы» |
| `offers` | плитка «Предложения» в коллекциях |
| `studio` | фото студии (запасной hero-кадр) |

Расширение можно любое из списка: `p-01.jpg`, `hero-1.png`, `cat-fresh.webp`.

Если имена непонятные — скрипт их перечислит и ничего не сломает. Можно также
скинуть фото как есть, без переименования: тогда их разложу вручную по составу
на снимке.

## Требования

- Фото свои или с правом использования на сайте (владелец разрешил брать кадры
  из карточки на Яндекс Картах — этого достаточно).
- Горизонтальные кадры для баннера: от 1600 px по длинной стороне.
- Товары: по одному фото на позицию, вертикальные или квадратные — обрежется по
  центру (`object-fit: cover`).
- Подпись к фото (`alt`) уже есть в моках; после замены фото её стоит уточнить
  в админке («Подпись к фото»).
